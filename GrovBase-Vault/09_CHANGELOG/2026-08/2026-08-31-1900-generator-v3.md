# Change
Date: 2026-08-31 ~19:00 UTC
Author/agent: Claude (Claude Code session)
Type: Feature — Generator V3: managed + custom workspaces, model system, gallery, image workflow

## Objective
Rebuild both generators to the supplied reference design: one-screen
workspaces (config left, living gallery right), customer-facing AI-model
selection in BOTH modes, session types (reklamowa/lifestyle), per-shot
briefs with "Zachowaj kadr referencyjny", inspiration images, image-details
modal, regenerate-with-corrections modal, mobile dock with bottom sheets.

## Before
Managed mode was a two-screen flow (session form → concept board) with shot
type cards; custom mode was the separate Studio with its own UI system; the
gallery lived only in /library (limit 60, no pagination); no image details,
no notes, no delete, no NOWE, no inspiration images, no 3:4.

## Implementation
- ONE workspace component (components/genv3/) serving /prompts (managed),
  /generator (custom) and /k/[cat]/[wf] (managed + category presets).
  Superseded components deleted: session-form, studio, recent-panel.
- Managed pipeline: prepare (hidden planner, 1–10 shots, session-type
  directive, customer briefs → sealed prompts) then client-driven
  per-concept generation (concurrency 2) — images land in the gallery as
  they finish, marked NOWE.
- Custom pipeline: single prompt (0/2000) + product refs + up to 5
  inspiration images (scene/style only; identity contract appended to the
  protected fidelity block server-side).
- Model system: ai_models + visible_managed/visible_custom (enforced
  server-side for client-chosen ids), badge (7 curated keys + custom label)
  + badge_tone, max_outputs, supported_aspect_ratios editable in admin;
  3:4 native on Google models only; capability-reactive UI everywhere.
- Gallery: keyset pagination (24/page, one signing batch), session-type
  chips, favourites, search, sort, grid/list, per-card regenerate/menu;
  thumbnails (640px webp) generated at store time.
- Image details: safe prompt only (customer's own text or seller-facing
  concept copy), model/format/date/ID, REAL edit actions through the tools
  pipeline (remove bg / upscale ×2 / expand), notes (definer RPC), copy
  image/URL, downloads via local format tool (JPG/PNG/WEBP + original).
  Unsupported operations shown honestly as "Wkrótce".
- Regenerate: correction text (0/500) appended server-side to the REAL
  prompt; model switch limited to reference-capable models; masks
  deliberately absent (no connected provider supports them).
- Money: partial-delivery refunds (0041 RPC), charged credits returned in
  results, quotes keyed on real model ids, in-flight guards on both
  regeneration paths, /api/generate whitelisted (origin pinned to custom,
  no costOverride/lineage from the client).
- Adversarial review workflow (4 dimensions → 24 findings → verified): 23
  confirmed and ALL fixed before deploy.

own words — session directives never enter customer_description); replay
fingerprint covers all render parameters; per-mode model visibility is
enforced, not just hidden; custom jobs can no longer claim engine lineage.
