# Feature Map

## Customer
- Home dashboard (greeting, stats, category grid, recent work)
- Category workspaces `/k/{moda|ecommerce|social|mailing|inne|matching}`
  each with own shot types, controls (marketplace/model/framing/platform/
  copy-space/surface) and ratio order — fed into the planner as directives
- Generator `/prompts` (engine mode) and `/generator` (custom prompts):
  product → references → shot types → toolbar (mode, model, ratio,
  resolution 1K/2K/4K where supported, shots 5–10, live price)
- Concept board: per-concept generate/regenerate, favorites
- Image tools `/tools` (8 utilities, some free, some paid)
- Library (generations, favorites, history, tool results, ZIP export)
- Products CRUD + CSV import, credits page, plan page, settings, support
- Video section `/wideo` — honest "coming soon" (VIDEO_ENABLED=false)

## Admin
Users/CRM (block, credits, roles) · workspaces · models & providers &
encrypted credentials · service catalog (tools pricing, maintenance mode) ·
plans & credit packages · CMS (landing) + media + inspirations · economics
(real API cost per generation, margins) · logs · support inbox
